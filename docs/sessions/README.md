# 📝 동네골목 — 세션 작업 지시서 (Sessions)

이 폴더는 형이 Claude Code에 작업 의뢰할 때 미리 정리한 **작업 지시서**를 보관한다. 한 세션 = 한 파일.

각 세션 파일은 그 세션에서 무엇을 어떻게 진행했는지의 **사후 추적 가능한 기록**이 된다. 결정의 맥락을 잊지 않기 위해, 그리고 며칠 뒤의 형 자신이 "왜 이때 이런 결정을 했지"를 짚을 수 있도록.

---

## 파일 명명 규칙

```
{week}_{session_letter}_{topic}.md
```

- `week`: 진행 주차 (생략 가능, 같은 주 내 세션이면 letter만 사용)
- `session_letter`: 같은 주차 내 세션 순서 (a, b, c, …)
- `topic`: 그 세션의 핵심 주제 (소문자, 영문 또는 짧은 식별자)

예: `2a_payment.md` (Week 6 Session 2-A — 결제 컨셉 격상)

## 작업 지시서 작성 패턴

각 세션 지시서는 다음 구조를 따른다 (느슨한 가이드):

1. **작업 개요** — 이 세션의 미션 한 단락
2. **컨텍스트** — 형이 이미 결정한 사항 / 풀려는 통증
3. **작업 단계** — 번호 매긴 구체 작업 항목
4. **commit 정책** — 단일 commit 메시지 또는 다수 commit 가이드
5. **작업 후 보고** — 체크리스트 + 다음 세션 한 줄

---

## 운영 노트

- 작업 지시서는 **세션 시작 전**에 형이 작성하고, 세션 중 Claude Code에 통째로 입력한다.
- 세션 중 발견된 사항이나 변경된 결정은 Claude Code가 별도 문서(MISSION/CONCEPT/ROADMAP 등)에 반영한다.
- 지시서 자체는 **변경하지 않는다** (역사 보존). 단, 사후 보강 노트는 파일 끝에 "Update Log" 형태로 추가 가능.
