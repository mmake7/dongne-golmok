# 🏪 동네골목 — Shops Mockup Data (염창동 파일럿)

> 50개 가게 목업. 데모용 데이터. 실제 가게가 아닌 가공의 가게이며, 거리/역 이름은 실제 사용.

---

## 데이터 스키마

각 가게는 다음 필드를 가진다:

```yaml
id: g001
name: 가게 이름 (가공)
owner_nick: 사장님 닉네임
type: 정착형 | 1인메이커 | 이동형(정기) | 이동형(가끔)
category: 카테고리 (자유 표현)
location:
  address: 강서구 염창동 OOO 또는 거리/역 인근 (가공 또는 일반 지명)
  schedule: 영업시간 (정착) 또는 출현 일정 (이동)
posts: 등록 글 예시 (3~5개) — AI가 검색·추천에 사용
tags: 검색 태그 (음식·도구·이벤트 등)
notes: 사장님 한 마디 또는 가게 특징 (선택)
```
