# 동네골목 (Dongne Golmok)

> 동네 친구에게 묻는 것처럼.
> 숨어있는 우리동네가게와 주민이 서로를 발견하는 곳.

---

## 이 프로젝트는

**투자자/협력자에게 보여줄 파일럿**으로, **AI 컨시어지가 우리 동네의 작은 가게들과 사용자의 상황을 매칭해주는 동네 알림 서비스**입니다.

- 출발: harbor.school 6주차 quest #5 (당근마켓 클론)
- 진화: 단순 클론 → 동네 입고 알림 → AI 컨시어지
- 현재: 본 프로젝트 진입 결정. quest 마감과 분리.
- 파일럿 지역: 서울 강서구 염창동
- 데이터: 50개 가게 목업으로 데모
