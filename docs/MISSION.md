# 🎯 동네골목 — MISSION

> 동네 친구에게 묻는 것처럼.
> 숨어있는 우리동네가게와 주민이 서로를 발견하는 곳.

---

## Project Name

**동네골목** (Dongne Golmok / GOLMOK)

워터마크·도메인·로고 표기는 영문 `GOLMOK.` 단축형 병행. 한국어 친근감과 글로벌 표기 가능성을 모두 살림.

---

## Mission Statement

**공식 상권 바깥에서 동네를 만드는 작은 가게들과, 그들을 단골로 누리는 주민들이, 서로를 자연스럽게 발견하는 동네 알림 생태계를 만든다.**

## Problem Statement

**작은 동네라도 정보가 많아지면 화면이 정신없이 표시된다. 사용자는 그 안에서 자기 상황에 맞는 답을 찾기 어렵다.**

구체적으로:

1. **주민 측 통증** — 동네에 뭐가 있는지 모름. 갔다가 없어서 헛걸음. 결국 큰 마트로 감.
2. **가게 측 통증** — 오늘 들어온 것·오늘 와있는 자리를 알릴 수단 없음. 단골 외 신규 고객 발견 0.
3. **연결의 부재** — 같은 동네에 사는데도 서로의 존재를 모름. 지도·인스타에 없는 가게가 너무 많음.

**기존 도구의 한계**:
- 네이버 지도/카카오맵 — 공식 등록된 가게 위주. 1인 메이커·트럭·노점 누락.
- 인스타그램 — 가게가 직접 운영해야 함. 동네 사장님들이 버거움.
- 당근마켓 — C2C 중고거래 영역. 가게의 입고·운영 정보와 모양이 다름.

**그래서 동네골목이 푸는 것**: 정보가 많아져도 **사용자 상황에 맞춰 AI가 정리해주는** 동네 알림판.

## Target Users

### 등록자 — "동네를 만드는 사람"

**숨어있는 우리동네가게**. 정의: **공식 상권에 안 잡히는 모든 소규모 주체**.

| 분류 | 예시 |
|---|---|
| 동네 음식점 | 떡집·정육점·반찬가게·분식·김밥·도시락·베이커리·치킨·중식·한식·일식·카페·디저트 |
| 의류·생활 서비스 | 양장점·세탁소·구두수선·열쇠·옷가게·신발·가방수선·이불 |
| 1인 메이커·공방 | 3D프린터·도자·캔들·비누·한복·한지·가죽 |
| 학원·동네 서비스 | 작은 미술학원·태권도장·공인중개사·이미용실·동네서점 |
| 농수산·정육 | 정육점·반찬·과일·생선·반건조 어물전 |
| 이동형 (정기) | 매주 화요일 순대차 · 목요일 양말차 · 주말 과일트럭 등 |
| 이동형 (가끔) | 다마코치·홍게·튀김·붕어빵 노점 |

**공통점**: 네이버 지도/인스타에 안 보임. 단골 관계가 핵심. "오늘 뭐 있는지" 알릴 수단 부재.

### 이용자 — "동네를 누리는 사람"

| 분류 | 특징 |
|---|---|
| 30~60대 동네 주민 | 단골 가게 가능성 높음. 헛걸음 통증 가장 큼. |
| 20~30대 1인 가구 | 동네 카페·트럭음식 발견 욕구. AI 친화적. |
| 통근자 | 퇴근길 동선에 무엇이 있는지 궁금. |
| 이주민·귀촌·신혼 | 이 동네에 뭐가 있는지 모르는 사람. 가장 도움받을 그룹. |

## Core Features (v1 Pilot)

> 파일럿이라 v1을 정확히 자른다. 데모에 필요한 것만.

1. **AI 컨시어지 (개인비서 톤)** — 사용자가 "밤 11시 순대 먹고 싶다" 같은 자연어를 던지면, AI가 동네 데이터를 검색해 한 줄 답변. 영업시간·요일·자리를 고려.

2. **오늘의 동네 한 줄 환영** — 앱 진입 시 "오늘 OO동에는 한과집 새 한과 한 판, 화요일이라 1번 출구에 순대차도 와있어요." 한 문장 환영.

3. **가게 목록 (동네 단위)** — 정착형/이동형 토글 필터. 카테고리 필터.

4. **가게 상세 페이지** — 사장님이 등록한 오늘의 입고·위치 정보 + 운영시간 + 사진.

5. **(목업 모드)** 가게 등록·수정 화면 — 데모용으로 1~2개 가게 라이브 등록 시연 가능.

### Feature Set 도식

```
앱 진입
  ↓
[1] 오늘의 동네 한 줄 환영
  ↓
[3] 가게 목록 (필터)  또는  [1] 검색창에 자연어 질문
  ↓                              ↓
[4] 가게 상세                [1] AI 한 줄 답변 + 추천 가게
```

## Anti-Scope (v1에서 안 할 것)

| 항목 | 이유 | 향후 |
|---|---|---|
| 1:1 채팅 | 실시간 들어가면 시간 폭발 | v1.5에서 **상점 게시판**으로 대체 |
| 결제 / 정산 | 동네골목은 직거래. 결제 없음 | 본질적으로 안 함 |
| 매너온도 / 평가 | 단골 신뢰가 다른 모양 | v2에서 **단골 등록** 형태로 |
| 푸시 알림 | 모바일 앱 영역. v1은 웹 | v1.5에서 PWA 검토 |
| 진짜 GPS | 행정동 단위로 충분 | v1.5에서 카카오맵 결합 |
| 개인화 추천 | v1은 동네 단위 한 줄로 충분 | v2에서 행동 로그 기반 |
| 실제 가게 모집 | 파일럿은 **목업 데이터** 운영 | v2 이후 실제 모집 |
| 가게 사장님 가입 폼 | 데모용 등록만 | v2에서 셀프 가입 |

## Success Metrics

> 파일럿이 "투자자·협력자에게 보여줄 데모"이므로 운영 지표가 아닌 **데모 임팩트 지표**.

### 1차 (v1 출시 시점)

| Metric | Target | 측정 방법 |
|---|---|---|
| 데모 가능한 시나리오 수 | 8개 이상 | 컨시어지 질문 → AI 답변 시나리오 |
| 목업 가게 데이터 | 50개 | shops_mock.json 확인 |
| 평균 컨시어지 응답 시간 | 3초 이내 | Claude API 응답 |
| 첫 방문자 "와 이거 신기하다" 반응 | 10명 중 7명 이상 | 1:1 시연 후 인터뷰 |

### 2차 (협력자/투자자 미팅 후)

| Metric | Target | 측정 방법 |
|---|---|---|
| 미팅 후 "더 알고 싶다" 응답 | 5건 이상 | 누리인포스 + 외부 |
| 협력 의사 표명 | 1건 이상 | LOI 또는 비공식 약속 |
| 염창동 실제 가게 사장님 인터뷰 동의 | 3건 이상 | v2 진입을 위한 1차 검증 |

## Pilot Scope — 염창동

### 왜 염창동인가

1. **형의 동네**. 운영자가 직접 거리를 걷고 가게 사장님을 만날 수 있음.
2. **강서구 가양·염창·등촌의 중심**. v2 확장 시 자연스러운 인접 동 추가.
3. **공식 상권과 비공식 상권이 공존**. 강서로·등촌로 같은 큰 길 + 골목 안 작은 가게.
4. **양천향교역·염창역 인근**. 통근자 많음 = 이용자 다양.

### 파일럿 데이터 구성 (목업)

총 **50개 가게**. 분포:

| 카테고리 | 비율 | 개수 |
|---|---|---|
| 동네 음식점 | 30% | 15 |
| 의류·생활 서비스 | 16% | 8 |
| 1인 메이커·공방 | 14% | 7 |
| 학원·동네 서비스 | 10% | 5 |
| 농수산·정육 | 10% | 5 |
| 이동형 (정기) | 12% | 6 |
| 이동형 (가끔) | 8% | 4 |

상세는 `shops_mock.md` 참조.

## Open Questions

> 이 문서를 첫 작성한 시점의 미결정 사항. 시간 두고 굴려야 할 것들.

1. **사이트 도메인** — `dongne-golmok.kr`, `golmok.kr`, `golmok.app` 중? 현재 미정.
2. **데이터 소스 수집 방식** (v2부터) — 가게 사장님이 직접 등록 vs 운영자(형)가 대리 등록 vs 하이브리드?
3. **AI 컨시어지의 페르소나** — 듀오 캐릭터(5주차 카페지기·달지기 패턴) vs 단일 동네 친구 톤? 파일럿은 단일로 가되 v2에서 검토.
4. **광고/PR 모델 진입 시점** — v2와 동시? 아니면 가게 50개 이상 모인 후? 형 PM 판단 영역.
5. **누리인포스 JV 편입 타이밍** — 파일럿 단계 vs v2 진입 시점? 형의 사업 전략과 연결.
6. **이름 — 동네골목 그대로 vs 별도 베타 이름** — 현재 그대로 유지 결정.
7. **법적 검토** — 동네 가게 정보를 무단 게시할 수 없으므로 v2 모집 시 동의 절차 필요.
